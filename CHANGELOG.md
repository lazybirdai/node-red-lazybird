# Changelog

## 0.1.0 (2026-11-03)

First release.

- lazybird speech node: text or SSML in, MP3 buffer out, with voice, locale, speed and more voice settings, set on the node or per message.
- Voice field with suggestions and search from your Lazybird account.
- lazybird-config node that keeps the API key in Node-RED's encrypted credentials.
- Example flow that saves speech to an MP3 file.
